# Подход

Приложение для ПК и Android: дела дня с сериями, калории и БЖУ, дневник тренировок с RPE, запасом повторов и прогрессом.
Работает без интернета. Данные синхронизируются между устройствами в зашифрованном виде через твой приватный репозиторий GitHub.

**Открыть:** https://wrt56syfly609g-lgtm.github.io/tracker/

## Установка

**ПК (Microsoft Edge).** Открой ссылку выше. Справа в адресной строке появится значок «Приложение доступно». Нажми его, потом «Установить».
Если значка нет: меню «…» → «Приложения» → «Установить этот сайт как приложение».

**Android (Microsoft Edge).** Открой ссылку → меню (три полоски или «…» внизу) → «Добавить на телефон» → «Установить».
Значок «Подход» появится на рабочем столе.

## Синхронизация (один раз)

1. Нужен **приватный** репозиторий `tracker-data`. В нём будет лежать только зашифрованный файл `data.enc`.
2. Создай ключ доступа: https://github.com/settings/personal-access-tokens/new
   - Token name: `Подход`
   - Expiration: максимальный срок. Запомни дату: её можно указать при подключении, и приложение напомнит за две недели
   - Repository access: **Only select repositories** → `tracker-data`
   - Permissions → Repository permissions → **Contents: Read and write**
   - Нажми «Generate token» и скопируй ключ (начинается с `github_pat_`).
3. На ПК в приложении: ⚙ Настройки → Синхронизация → «Первое устройство»:
   вставь ключ, по желанию дату окончания ключа, репозиторий `wrt56syfly609g-lgtm/tracker-data`, придумай пароль (от 8 символов) → «Подключить» → повтори пароль.
   **Запиши пароль.** Без него данные не расшифровать, восстановить его нельзя.
4. Телефон: на ПК нажми «Подключить телефон / ПК», появится QR-код.
   На телефоне в приложении: ⚙ Настройки → «Сканировать QR-код» → введи тот же пароль → «Подключить по коду».
   Вместо QR можно скопировать код и вставить его в поле «Код подключения».

Дальше всё синхронизируется само: при открытии и сворачивании приложения, через минуту после правок и сразу после тренировки.
Во время тренировки отправка идёт только при сворачивании: каждая отправка — новая версия в репозитории, и так их не сотни в день.
Без интернета всё работает, догоняет потом. Правки с двух устройств сливаются по каждой записи.

## Безопасность

- Данные сжимаются и шифруются на устройстве (AES-256-GCM, ключ из пароля через PBKDF2, 310 000 итераций).
  GitHub и любой, кто получит файл, видят только зашифрованный набор символов.
- Пароль никуда не отправляется. На устройстве хранится только производный ключ, который нельзя извлечь.
- Ключ GitHub даёт доступ только к одному репозиторию с данными. Внутри QR-кода и в файле данных (чтобы новый ключ доходил до всех устройств) он тоже зашифрован паролем.
- Код самого приложения открытый (так работает бесплатная публикация GitHub Pages), но в нём нет твоих данных.

## Если что-то пошло не так

- **После обновления пустой экран**: с версии 1.2.2 приложение чинится само. Открой его и подожди пару секунд: окно перезагрузится уже с новыми файлами. Если экран так и остался пустым, через несколько секунд появится кнопка «Скачать приложение заново»: она заново скачивает файлы приложения, данные не трогает.
  Не очищай данные сайта в настройках браузера: это удалит записи на устройстве.
- **Ключ скоро истечёт или истёк**: создай новый ключ (шаг 2), затем Настройки → Синхронизация → «Заменить ключ». Пароль остаётся прежним.
  Остальные устройства получат новый ключ сами при следующей синхронизации, если их старый ключ ещё работает. Если уже не работает — подключи их заново по QR-коду.
- **Вернуть старые данные**: Настройки → «История версий». Версии сгруппированы по дням: «Конец дня» возвращает данные такими, какими они были вечером, а «Все версии дня» — к любой отправке. «Показать раньше» подгружает старые дни.
- **Резервная копия**: Настройки → «Скачать файл». Файл не зашифрован, храни его надёжно.
- **Забыл пароль**: расшифровать данные в репозитории нельзя. Данные на уже подключённых устройствах останутся:
  скачай резервную копию, отключи синхронизацию, очисти файл `data.enc` в репозитории и подключись с новым паролем.

## Еда: таблица КБЖУ и подсчёт по весу

Еда → «Добавить». Начни вводить название, выбери продукт или блюдо из подсказок и впиши вес в граммах.
Калории, белки, жиры, углеводы и клетчатка посчитаются сами. Любую цифру можно поправить: если потом изменить вес, пропорция сохранится.

- **Встроенная таблица**: 424 продукта и блюда на 100 г: крупы сухие и варёные, мясо и птица (крылья, бёдра и голени есть и «с костями»),
  рыба, молочное (творог 0–18 %), 30+ сыров от качотты до сулугуни, овощи, фрукты, орехи, соусы, сладкое, напитки, супы, вторые блюда,
  салаты, фастфуд и лапша быстрого приготовления. Значения взяты из таблиц Скурихина и USDA (углеводы без клетчатки), блюда посчитаны
  по домашней рецептуре. Цифры примерные, сверяй с этикеткой.
- **Количество в строке**: можно написать «гречка 80 г», «2 шт яйца», «роллтон 1 пачка», «масло 1 ст. л.». У продуктов со штуками
  (яйцо, банан, ломтик хлеба, пачка лапши) есть кнопки ½, 1, 2, 3, 4.
- **Свой продукт добавляется один раз**: в подсказках пункт «Новый продукт», кнопка «Сохранить как мой продукт» или «Таблица КБЖУ» → «Новый продукт».
  Значения вписываются на 100 г, можно указать вес одной штуки. Свои продукты стоят в подсказках первыми и синхронизируются между устройствами.
- **Правка таблицы**: «Таблица КБЖУ» → нажми на строку. У встроенных продуктов есть «Вернуть исходные значения».
- **Блюдо из ингредиентов**: добавь продукты с весом и, если хочешь точнее, вес готового блюда (крупа впитывает воду, мясо её теряет).
  Значения на 100 г посчитаются сами, блюдо сохранится как продукт.
- **Клетчатка**: цель 14 г на 1000 ккал, но не меньше 25 г (Настройки → «Цель и КБЖУ», можно задать своё число).

## Тренировки дома: типы, стороны, суперсеты

- **Тип упражнения** (Библиотека → упражнение → «Тип»): с весом, свой вес, свой вес + груз, резина, на время.
  От типа зависят колонки подхода: у подтягиваний только повторы, у «свой вес + груз» — добавочный вес (можно пусто),
  у виса — секунды. Все отмеченные подходы идут в статистику и рекорды, не только подходы с весом.
- **На каждую сторону** (переключатель там же): у подхода две колонки, «Левая» и «Правая», левая первая.
  Кнопка «Левой» добавляет подход только левой, в шаблоне это «+1 левой». В статистике у таких упражнений видно, сколько процентов
  от правой делает левая и как это меняется.
- **Суперсеты и круги**: в шаблоне «сразу следующее» у всех упражнений группы, кроме последнего, во время тренировки — значок цепочки.
  После галочки экран переходит к следующему упражнению группы без отдыха, после последнего запускается отдых (берётся у последнего)
  и экран возвращается к первому. У обычного упражнения после последнего подхода экран переходит к следующему.
- **Отчёт для Claude** (Статистика или Тренировка → «Отчёт для Claude»): тренировки с подходами и запасом, вес, питание и сон
  за 2, 4 или 8 недель и текущая программа в формате импорта. Вставь в чат с Claude — правки к программе можно сразу импортировать.

## Обмен программами и упражнениями

Тренировка → карточка «Упражнения» → **Экспорт** или **Импорт**.

- **Экспорт.** Выбери шаблоны (это программа целиком) и/или отдельные упражнения пачкой: группа мышц, «Выбрать все» или по одному.
  Дальше «Скопировать», «Скачать файл», «Ссылка» или «Поделиться». Текст удобно отправить в мессенджер, заметки или Claude.
  Ссылка открывает «Подход» сразу с импортом; данные лежат в самой ссылке после `#` и на сервер не уходят.
- **Импорт.** Вставь текст или JSON, выбери файл или открой ссылку. Перед загрузкой видно, что добавится и что изменится.
  Упражнения с тем же названием не задваиваются, шаблон с тем же названием заменяется. После импорта есть кнопка «Вернуть».

Текстовый формат (так же выглядит экспорт, так можно писать руками или попросить Claude):

```
Шаблон: Д1 Верх-сила
Подтягивания | Спина | свой вес | 3×5–8 | отдых 2:00
Тяга гири в наклоне одной рукой | Спина | на каждую сторону | 3×8–12 | сразу следующее | шаг 8
Отжимания от пола | Грудь | свой вес | 3×8–12 | отдых 2:00
Молот с гирей на полотенце | Руки | на каждую сторону | 3×6–10 | +1 подход левой

Упражнения:
Вис на полотенцах | Предплечья | на время
Планка | Кор | на время
```

- Одна строка — одно упражнение. После названия всё необязательно и в любом порядке, через `|`, `;` или табуляцию.
- Группа: Грудь, Спина, Ноги, Плечи, Руки, Предплечья, Кор (понимает и «пресс», «бицепс», «хват»…). Не указана — подставится по названию.
- Подходы × повторы: `3×8–12`, `4×6`, `3×20–30 с`, `3 подхода по 10`. Всё после × становится целью, она видна во время тренировки.
- Отдых: `отдых 90`, `отдых 2:30`, `2 мин`. Шаг веса: `шаг 8`.
- Тип: `свой вес`, `свой вес + груз`, `резина`, `на время`, `с весом` (по умолчанию). Не указан — угадывается по названию
  («подтягивания» — свой вес, «с резиной» — резина), а цель в секундах (`3×20 с`) — на время.
- На каждую сторону: `на каждую сторону`, `/р`, `/н`, `на сторону`. Лишний подход левой: `+1 подход левой` или `левой 4 подхода, правой 3`.
- Суперсет или круг: `сразу следующее` (или `круг`, `суперсет`) у всех упражнений группы, кроме последнего. Старый обход `отдых 0:15` у таких строк отбрасывается.
- `Шаблон: название` начинает шаблон. Строки после `Упражнения:` просто добавляются в библиотеку. Строки с `//` — комментарии.
- Понимает и таблицы из Markdown или скопированные из документа, JSON из экспорта и файл резервной копии.

## Как считается

- **Пассивный расход**: базовый обмен по Кэтчу–МакАрдлу (370 + 21,6 × масса без жира) × бытовая активность. Можно задать своё число.
- **Тренировка**: MET × вес × часы (MET по умолчанию 5). Можно поправить вручную у каждой тренировки.
- **Модель веса и % жира**: каждый день с записанной едой добавляет баланс / 7700 ккал к весу.
  При дефиците 3/4 изменения считается жиром, при профиците половина. Новые замеры вписываются в настройках, модель продолжает от них.
- **RPE и запас (RIR)**: шкала Зурдоса: RPE = 10 − запас повторов.
- **Расчётный максимум (e1RM)**: вес × (1 + (повторы + запас) / 30). По нему считается прогресс в процентах у упражнений с весом.
  У «свой вес + груз» вместо веса берётся вес тела по модели плюс груз. У «свой вес» и «резины» прогресс и рекорды — по лучшему подходу
  в повторах, у «на время» — по самому долгому удержанию. У упражнений на каждую сторону рекорд считается отдельно для левой и правой.
- **Тоннаж**: только внешний вес (гиря, груз), свой вес и резина в него не входят.
- **Левая к правой**: сумма повторов левой к сумме правой в подходах на обе стороны (подходы только левой не входят).
- **sRPE**: общая усталость за тренировку 1–10. Если три тренировки подряд с усталостью 8+, приложение предложит облегчить следующую.
- **Готовность**: из сна (часы и качество) и самочувствия, 0–100.

## Устройство (для доработок)

Без сборки и зависимостей: обычные файлы, которые GitHub Pages отдаёт как есть.

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы |
| `css/app.css` | стили, цвета светлой и тёмной темы |
| `js/app.js` | запуск, навигация, выбор даты, перерисовка |
| `js/store.js` | данные, хранение на устройстве (IndexedDB), слияние, стартовые привычки и упражнения |
| `js/calc.js` | все расчёты: даты, калории, модель веса, серии, e1RM |
| `js/sync.js` | шифрование и синхронизация с GitHub |
| `js/exchange.js` | формат обмена: экспорт в текст/JSON/ссылку, разбор импорта (тип, стороны, суперсеты) |
| `js/report.js` | отчёт для Claude: тренировки, питание, сон и программа одним текстом |
| `js/foods-data.js` | встроенная таблица продуктов и блюд: КБЖУ и клетчатка на 100 г |
| `js/foods.js` | база продуктов: свои продукты и правки, поиск, подсчёт порции и блюда |
| `js/ui.js`, `js/charts.js`, `js/timer.js` | элементы интерфейса, графики, таймер отдыха |
| `js/views/*.js` | разделы: Сегодня, Рутина, Еда, Тренировка, Статистика, Настройки |
| `sw.js` | работа без интернета |
| `tests/` | проверки обмена, тренировок дома, базы продуктов, слияния и синхронизации: `node --test tests/*.test.mjs` (Node 22+) |

**Выпуск обновления:** после правок поменяй `VERSION` в `sw.js` (например, `podhod-1.3.1`) и в `js/views/settings.js`.
Если добавлен новый файл, допиши его в список `FILES` там же. Устройства подхватят обновление при следующем запуске.
